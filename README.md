# Alise-patcher

Патчи и инструменты для Яндекс Станций с Алисой: root-доступ,
который переживает сброс, и гостевой режим без облака.

## Как это работает (кратко)

Проблема: на рутованной станции сетевой ADB держится на двух вещах —
файлах-маркерах в `/data/quasar` и стороже `rootkeeper.sh`. Сброс
к заводским стирает `/data` целиком, поэтому после сброса
`activate_adb.sh check` не находит маркеров, тихо выходит — и adbd
не стартует. Порт 5555 закрыт, доступа к станции больше нет.

Решение: системный раздел (`/system`) сброс **не трогает**. Патч
добавляет 12 строк в `/system/vendor/quasar/onboot.sh` — они
выполняются на каждой загрузке **до** проверки маркеров и делают две
вещи: пересоздают оба маркера (`activate_adb_quasmodrom`,
`activate_network_adb`) и восстанавливают `rootkeeper.sh` из эталона,
лежащего в `/system`. Дальше штатная цепочка видит маркеры и поднимает
adbd, а сторож следит, чтобы LISTEN на :5555 не пропадал.

Итог: сброс больше не убивает ADB. На обычных перезагрузках патч —
полный no-op (guard'ы пропускают `cp`, `touch` лишь обновляет mtime).

Подробный разбор — с цепочкой загрузки, механикой wipe, построчным
разбором патча и границами — в [adb-persist/README.md](adb-persist/README.md).

## Быстрый старт

Требования на хосте: `bash`, `adb`, `patch`. Станция доступна по ADB.
Скрипт единый для всех моделей, устройство выбирается флагом `--device`.

```bash
cd adb-persist/

# Проверить состояние (только чтение)
./adb-persist.sh verify [--device IP:PORT]

# Установить (бэкап → патч → проверка → remount ro)
./adb-persist.sh install [--device IP:PORT] [--reboot]

# Откатить к стоковому onboot.sh
./adb-persist.sh uninstall [--device IP:PORT] [--reboot]
```

скрипт при этом остаётся один на всех.

## Границы (коротко)

- Патч гарантирует LISTEN :5555, но не сеть: после сброса станцию
  надо искать в её setup-сети, а не в домашней.
- OTA-обновление перезапишет `/system` и сотрёт патч (маркеры в
  `/data` при этом выживут). Переприменение — одна команда `install`.
- Полный wipe на железе не тестировался — только симуляция.
